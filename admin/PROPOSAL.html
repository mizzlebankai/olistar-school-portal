1. Executive Summary

This proposal outlines the deployment and annual cloud infrastructure requirements for the official Olistar Educational Complex Web Portal & Online Admissions System. While the complete frontend user interface, customized administrative portal, automated application generator, and database architecture development labor are provided free of service charge ($0.00), this statement covers the essential managed server, domain, security, and search engine infrastructure needed to operate the system reliably 24/7.

3. Domain Strategy Options
  • Option A (Recommended): olistar.edu.gh – Requires official school registration documents (GES certificate / Registrar General's documents). Provides highest official authority and trust for parents in Ghana.
  • Option B (Fast-Track): olistaredu.com / olistareschool.education – Can be activated instantly within minutes without document verification delays.
4. Core System Deliverables
  • Official School Web Portal: Public informational portal detailing academic divisions, facilities, and contact channels.
  • Digital Admission System: Public application portal issuing unique reference numbers (e.g., OLI-XXXXXX).
  • Automated PDF Receipts: Immediate generation of printable application summary sheets featuring official headers upon submission.
  • Secure Administrative Portal: Dashboard for school administrators to search, filter, review documents, and update applicant statuses in real-time.
  • Search Engine & Maps Visibility: Indexing on Google Search and linkage to Google Maps for parents searching locally.
